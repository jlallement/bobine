# Raccourcis clavier

Les raccourcis de Bobine, menu par menu. Ceux des menus marchent partout dans la fenêtre, même
quand le clavier est dans le terminal ou dans une page du navigateur intégré.

La même liste se trouve dans l'app : Aide › Raccourcis clavier (⌘/), ou Réglages › Raccourcis
clavier.

Les menus Édition et Fenêtre ont aussi les raccourcis habituels de macOS (⌘Z, ⌘C, ⌘V, ⌘A, ⌘M…).
Aide › Diagnostic… et Aide › Afficher le journal n'ont pas de raccourci.

<a id="fenetre-rapide"></a>

## Fenêtre rapide

⌥⌘B ouvre la fenêtre rapide depuis n'importe quelle app, même quand Bobine n'est pas au premier
plan. Pour changer ce raccourci : Réglages › Général › Fenêtre rapide, au choix ⌥⌘B, ⌥Espace,
⇧⌥Espace ou Désactivé. Si une autre app a déjà pris le raccourci, Bobine le dit sous le réglage ;
la fenêtre rapide reste dans le menu Fichier.

<a id="saisie"></a>

## Dans la zone de saisie

<!-- raccourcis:saisie -->
| Touche | Ce qu'elle fait |
|---|---|
| ↩ | Envoyer le message |
| ⇧↩ | Nouvelle ligne |
| ⇧⇥ | Changer de mode (agent, plan…) |
| Échap | Arrêter la réponse, fermer un menu |
| / | Commandes (en début de message) |
| @ | Joindre un fichier du dossier |
| ↑ | Dans une zone vide, reprendre le dernier message en attente |
| 1 à 9 | Choisir une réponse dans une question |
<!-- /raccourcis:saisie -->

Dans les menus `/` et `@` : ↑ et ↓ changent de ligne, ↩ ou ⇥ choisissent (⇥ complète une commande
sans l'envoyer), Échap referme le menu.

<a id="dialogues"></a>

## Dans les dialogues et les remarques

⌘↩ valide sans quitter le clavier : « Lancer en parallèle… », « Faire relire… », une remarque sur
une ligne du diff, une remarque sur une page annotée. Échap ferme le dialogue.

Dans les réglages, ⌘F va au champ de recherche.

<a id="navigateur"></a>

## Dans le navigateur intégré

Quand la page a le focus :

| Raccourci | Ce qu'il fait |
|---|---|
| ⌘+, ⌘−, ⌘0 | Zoomer la page, la dézoomer, la remettre à 100 % |
| ⌘L | Aller à la barre d'adresse |
| ⌘R | Recharger la page |
| ⌘[ et ⌘] | Page précédente, page suivante |
| Échap | Quitter le mode Annoter |

Quand la page n'a pas le focus, ⌘+, ⌘− et ⌘0 zooment toute l'interface de Bobine.

Voir aussi : [Panneaux](panneaux.md#navigateur).
