# Keyboard shortcuts

Bobine’s shortcuts, menu by menu. Menu shortcuts work anywhere in the window, even when the
keyboard is in the terminal or in a page of the built-in browser.

The same list is in the app: Help › Keyboard Shortcuts (⌘/), or Settings › Keyboard shortcuts.

Help › Diagnostics… and Help › Show Log have no shortcut.

## Quick Entry

⌥⌘B opens Quick Entry from any app, even when Bobine isn’t in front. To change this shortcut:
Settings › General › Quick Entry, choosing ⌥⌘B, ⌥Space, ⇧⌥Space or Off. If another app has
already taken the shortcut, Bobine says so below the setting; Quick Entry stays in the File menu.

<a id="saisie"></a>

## In the message box

<!-- raccourcis:saisie -->
| Key | What it does |
|---|---|
| ↩ | Send the message |
| ⇧↩ | New line |
| ⇧⇥ | Switch mode (agent, plan…) |
| Esc | Stop the response, close a menu |
| / | Commands (at the start of a message) |
| @ | Attach a file from the folder |
| ↑ | In an empty box, bring back the last queued message |
| 1–9 | Choose an answer in a question |
<!-- /raccourcis:saisie -->

In the `/` and `@` menus: ↑ and ↓ move between lines, ↩ or ⇥ choose (⇥ completes a command
without sending it), Esc closes the menu.

<a id="dialogues"></a>

## In dialogs and comments

⌘↩ confirms without leaving the keyboard: “Run in parallel…”, “Request review…”, a comment on a
diff line, a comment on an annotated page. Esc closes the dialog.

In Settings, ⌘F goes to the search field.

<a id="navigateur"></a>

## In the built-in browser

When the page is focused:

| Shortcut | What it does |
|---|---|
| ⌘+, ⌘−, ⌘0 | Zoom the page in, out, back to 100% |
| ⌘L | Go to the address bar |
| ⌘R | Reload the page |
| ⌘[ and ⌘] | Previous page, next page |
| Esc | Exit annotation mode |

When the page isn’t focused, ⌘+, ⌘− and ⌘0 zoom all of Bobine’s interface.

See also: [Panels](panneaux.md#navigateur).
