Vue des fichiers — maquettes (fiche 271)

Option recommandée B : l'onglet Fichiers de Claude Code (desktop), relevé sur l'app réelle, en lecture seule (décision de l'utilisateur), avec la coloration de code et le commentaire sur une ligne envoyé à l'agent (écrans 0 à 4). Corrigées le 2026-11-20 selon les réponses de l'utilisateur (docs/features/271-questions.md) : pas de palette, ⌘P met le curseur dans le filtre, la ligne « Dossier » de Session garde le Finder, un .env s'affiche comme un autre fichier.

Couleurs et polices de Bobine (themes.generated.css, styles.css) ; coloration : les jetons --syn-* de syntax.css, ceux du code du fil. Pastilles jaunes : renvois à la légende, qui dit ce que ça fait et, en gris, ce que ça ne fait pas. Données fictives (un projet « carnet »).

« L'idée, c'est de ne pas faire un truc comme Bob IDE, un IDE en premier et Bob en secondaire, mais plutôt dans l'esprit de Claude Code. Si on en a besoin, on peut voir l'arborescence et les fichiers, mais pas de manière centrale dans le logiciel. » — l'utilisateur, 2026-11-20. Puis : lecture seule d'abord ; « la coloration de code, ce serait aussi un vrai plus ».
