# La Bobinette

Le petit projet qui sert aux démonstrations de Bobine :

| Dossier | Contenu |
|---|---|
| `site/` | Le site du café : accueil, boutique, inscription, animation, formes |
| `calculs/` | Les calculs du panier en Python, avec leurs tests |
| `apps/ios/` | « Pastilles », une petite app iPhone en SwiftUI |
| `apps/android/` | La même app pour Android, en Java |
| `AGENTS.md` | Les consignes lues par l'agent |
